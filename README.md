# security-projects

Security tools, automation scripts, and practical cybersecurity projects — built for real-world use.

## Tools

| Tool | Language | Description |
|------|----------|-------------|
| [secret-scan](./secret-scan) | Python | Secrets scanner for codebases and git history — 100+ rules, Shannon entropy, zero dependencies |

## Philosophy

Every tool here is:
- **Tested** — unit tests ship with the code
- **Zero or minimal dependencies** — runs anywhere Python does
- **Cross-platform** — Linux, macOS, Windows

## Install Any Tool

```bash
git clone https://github.com/blind-sec/security-projects
cd security-projects/<tool-name>
pip install -e .
```
